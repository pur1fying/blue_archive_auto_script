# Wikiru portrait source notice

These original PNG files were downloaded on 2026-08-06 from the Japanese
[Blue Archive character list](https://bluearchive.wikiru.jp/?%E3%82%AD%E3%83%A3%E3%83%A9%E3%82%AF%E3%82%BF%E3%83%BC%E4%B8%80%E8%A6%A7)
as development-only identity-classification seed data.

The source site states that it quotes images under Article 32 of the Japanese
Copyright Act, that copyright belongs to the respective rights holders, and
asks readers not to reproduce or reuse those images. Checking these files into
this repository records the data-source decision requested for this experiment;
it does not grant, represent, or imply redistribution permission. Repository
maintainers should review the source site's notice before accepting the data.

`manifest.json` records the source URL, original Japanese label, local canonical
identity, dimensions, byte length, SHA-256, and training-selection flag for
every file. Hoshino (Battle) and Shun (Swimsuit) each have two source forms;
both are archived, but only the first form is selected for identity training.
The source files are preserved byte-for-byte: 262 are 200×200, eight legacy
portraits are 198×198, and two are 300×300. They are not resized or re-encoded
in the committed source library.
